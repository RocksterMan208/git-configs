# This is my personal Hyprland rice for Arch Linux
### These packages are required:
- Hyprland **OR** Sway
- Waybar
- Wofi
- kitty
- yazi
- grim
- slurp
- NerdFonts (for icons)

### Changes to this repo are infrequent, because I usually back up if something goes wrong with my device

# Installation
To install, first clone the repo.
```
git clone https://github.com/RocksterMan208/git-configs
```
Move terminal into the directory
```
cd git-configs
```
Remove the .git file and ReadMe
```
rm -rf .git
```
```
rm README.md
```
Now move it into your .config file
```
mv * ~/.config
```
